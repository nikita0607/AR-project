Подробное описание

Реализует медианный фильтр для сглаживания значений Vector3.

Методы

◆ Filter()

Vector3 Utilities.MedianFilterVector3.Filter ( Vector3 value,
float maxDelta,
int windowSize = 5 )

Применяет медианный фильтр к входному значению.

Аргументы
valueВходное значение для фильтрации.
maxDeltaМаксимально допустимое отклонение от медианы.
windowSizeРазмер окна фильтра (по умолчанию 5).
Возвращает
Отфильтрованное значение Vector3.

Алгоритм:

  1. Добавляет значение в окно фильтра
  2. Поддерживает заданный размер окна
  3. Находит медиану по расстоянию от предыдущей медианы
  4. Возвращает медиану, если отклонение в пределах maxDelta, иначе исходное значение
