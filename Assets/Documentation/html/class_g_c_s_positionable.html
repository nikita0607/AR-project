◆ FromLongLat()

static Vector3 GCSPositionable.FromLongLat ( float longitude,
float latitude,
float radius )
static

Преобразует географические координаты в GCS координаты.

Аргументы
longitudeДолгота в градусах.
latitudeШирота в градусах.
radiusРадиус от центра Земли.
Возвращает
Вектор позиции в GCS системе координат.

Формулы преобразования: omega = π/2 - latitude (в радианах) phi = longitude (в радианах) x = radius * sin(omega) * cos(phi) y = radius * sin(omega) * sin(phi) z = radius * cos(omega) Окончательный вектор: (x, z, -y) для соответствия Unity-координатам
