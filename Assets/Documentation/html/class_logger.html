Предоставляет статические методы для логирования сообщений в Unity-консоль и/или файл.

Методы

◆ EnableFileLogging()

static void Logger.EnableFileLogging ( string filename)
static

Включает логирование в файл и устанавливает имя файла для логирования.

Аргументы
filenameПолный путь к файлу для сохранения логов.

После вызова этого метода все последующие вызовы Log() будут записывать сообщения в указанный файл. Файл будет создан, если не существует, или дополнен, если уже существует.
